# Automatización con IA + n8n 🤖⚙️

Portfolio de proyectos de automatización desarrollados con **n8n**, integrando modelos de IA (Cohere, Groq/OpenAI) para resolver casos reales de atención al cliente, procesamiento de correos, generación de informes y gestión de pedidos.

> Serie de ejercicios progresivos del curso de Automatización con IA (Alura).

---

## 📂 Proyectos

| # | Proyecto | Descripción | Repositorio |
|---|---|---|---|
| 1 | **Resumen de Correos con IA** | Primer workflow: recibe correos extensos por Gmail y genera un resumen ejecutivo con IA. | [Clase1_Resumen_de_correos_con_IA](https://github.com/danielarse/Clase1_Resumen_de_correos_con_IA) |
| 2 | **Atención al Cliente Inteligente** | Clasifica consultas de clientes (SIMPLE / COMPLEJA) con un agente IA y responde automáticamente o deriva a un agente humano. | [Clase2_Atenci-n_al_cliente_inteligente](https://github.com/danielarse/Clase2_Atenci-n_al_cliente_inteligente) |
| 3 | **Organización de Informes Automatizados** | Automatización de generación y envío de informes usando Cohere y Outlook. | [Clase3_Organizaci-n_de_informes_automatizados](https://github.com/danielarse/Clase3_Organizaci-n_de_informes_automatizados) |
| 4 | **Seguimiento de Reclamos y Comentarios** | Workflow de triage y seguimiento de reclamos/comentarios de clientes, usando la plataforma Groq. | [Clase4-seguimiento-reclamos-comentarios-n8n](https://github.com/danielarse/Clase4-seguimiento-reclamos-comentarios-n8n) |
| 5 | **FlexData — Agente de Pedidos** | Automatización completa de atención al cliente para gestión de pedidos (migración de Chat Model de OpenAI a Cohere). | [Clase5-flexdata-agente-pedidos-n8n](https://github.com/danielarse/Clase5-flexdata-agente-pedidos-n8n) |

---

## 🛠️ Stack utilizado

- **n8n** — orquestación de workflows
- **Cohere** (`command-a-03-2025`) — modelo de lenguaje principal
- **Groq** — modelo de lenguaje alternativo (Clase 4)
- **Gmail / Microsoft Outlook** — canales de entrada y salida de correo

## 📈 Progresión del curso

Cada clase construye sobre conceptos de la anterior: desde un flujo lineal simple (Clase 1) hasta agentes con clasificación, bifurcaciones condicionales y múltiples integraciones (Clases 2–5).
